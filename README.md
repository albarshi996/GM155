---

نموذج تصوّري ثلاثي الأبعاد لمستودعات **برندزو — موقع أبوهادي 155، بنغازي**، مبنيّ ليطابق المخطط الفعلي
`NAS-8155-ARC` في التوزيع والمساحات، ويعكس متطلبات التنفيذ الهندسية (22 محورًا)، والقوى العاملة والقطاعات، والزيّ الموحّد.

## المحتوى
- **5 مناطق تشغيلية** (Z1 الإدارة · Z2 المواقف والبوابة · Z3 الثلاجات · Z4 المستودعات الرئيسية · Z5 الجنوبية).
- **10 مخازن جافة** (E-1..E-10، 18,850م²) + **مجمّع مبرّد E-F** (3,850م²).
- العائلات: غذائي جاف · مشروبات · مبرّد/مجمّد · ملابس · ألعاب/مدينة الألعاب · تغليف.
- منصّات تحميل (1.20م + Dock Leveler)، رفوف معبأة بالبليت، وتدفّق الدخول.

## العارض التفاعلي (`viewer.html`)
تنقّل حرّ · **وضع مشي بمنظور أول** (WASD + سحب للنظر) · **جولة تلقائية** · دخول إلى كل مخزن · لافتات مصنّفة بالألوان.

## الملفات
| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية + معرض اللقطات |
| `viewer.html` | العارض ثلاثي الأبعاد التفاعلي (Three.js) |
| `site_scene.js` | بيانات المشهد (يولّدها `build_site.py`) |
| `build_site.py` | مولّد النموذج (Python، بلا مكتبات خارجية) |
| `blender_build.py` | بناء المشهد وإخراج اللقطات في Blender (Cycles) |
| `gallery/` | لقطات مُخرَجة من Blender |

## التوليد محليًّا
```bash
python build_site.py          # يولّد site_scene.js / .json / OBJ
# ثم افتح viewer.html (عبر خادم محلّي بسيط):
python -m http.server 8000    # ثم http://localhost:8000/
```
